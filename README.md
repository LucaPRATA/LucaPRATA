### What we actually build

Anyone can call a model. What is hard is running a hundred agents against a
real estate of services and still knowing, a month later, who decided what, on
what evidence, and what it cost.

**AEGIS** is the layer that makes that possible: shared memory, explicit
permissions per role, every decision and every doubt written down at the moment
it happens. **Talos** coordinates — it routes work to the right agent and runs
the part that needs no person in front of it.

People decide. The agents carry the work.

### The tools

Each one came out of a defect we measured on our own estate, and each carries
the self-test that found it.

| Name |  What is it? |
|---|---|
| [kemproof](https://github.com/langacorp/kemproof) | attest an ML-KEM-768 key exchange — and say only what that proves |
| [leakform](https://github.com/langacorp/leakform) | find secrets in a git repository by shape, across every ref |
| [realroute](https://github.com/langacorp/realroute) | check a route exists by content, not by status code |
| [samecheck](https://github.com/langacorp/samecheck) | measure whether copies that should be identical still are |
| [provenreal](https://github.com/langacorp/provenreal) | compare what a system claims with what can be measured |
| [countdrift](https://github.com/langacorp/countdrift) | find numbers written by hand that no longer match their source |
